AZ Portfolio Source
===================

Laravel-powered content and API platform for the AZ Portfolio React
application.

Purpose
-------
Provides portfolio content through a structured API and serves as the
backend/content source for the AZ Portfolio frontend.

Technology
----------

PHP
MySQL
Docker
